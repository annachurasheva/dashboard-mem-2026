# Ленты: Дзен и ОК/ВК

  варианта /ru/rss.xml/ нет). Лента карточек: /ru/memorial/rss.xml/.
- Дзен, первая разметка: минимум 10 материалов; enclosure ≥700 px; guid стабилен;

- category: native-draft для черновиков, format-article/format-post по объёму.
